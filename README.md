# Indian Job Market Intelligence Analysis

## Project Overview
This project analyzes the Indian job market to understand job opportunities, salary trends, experience requirements and in-demand skills using data analytics tools.

## Project Dashboards

### 1. Indian Job Market Intelligence Overview
Provides an overall view of job opportunities, job categories, work modes and market insights.

### 2. Salary and Experience Analysis
Analyzes salary trends, experience levels, job roles and salary distribution.

### 3. Skills Demand Tracker
Analyzes in-demand skills, skill distribution and skills required across different job roles.

## Tools & Technologies
- Excel
- SQL
- Python
- Pandas
- Power BI
- Power Query

## Project Workflow
- Data Cleaning
- Data Preprocessing
- Data Analysis
- Data Transformation
- Dashboard Development
- Data Visualization

## Project Objective
To explore the Indian job market through data-driven insights and understand salary trends, experience requirements and in-demand technical skills.
